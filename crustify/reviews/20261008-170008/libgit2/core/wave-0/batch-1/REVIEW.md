# Review: libgit2 / core / wave 0 / batch 1 (symbols: `git_libgit2_{init,shutdown,version,prerelease,features,opts}`)

Reviewed commit `ab5de9104` (wave base; the items landed in `7fc5171aa`, wave 0
batch 8): `init` / `Runtime` / `Runtime::shutdown` in
`crustify/rust/libgit2/libgit2/core/global.rs`, and `version`, `prerelease`,
`features` and the 49 per-key `git_libgit2_opts` wrappers (plus `LibraryOption`,
`SearchPathLevel`, `CachedMemory`, `Version`) in

(`review-wave-0/bsan-gate.log`) stops inside the `equiv` suite on a type-batch test
(`types::from_raw_names_exactly_the_c_modes`, batch 0's item) before `ub_safe` /
`ub_unsafe` ran; every `common` and `global` test it did reach passed, and this review
reran BSan on all four suites for both modules.

Regressions: `tests/ub_unsafe/common.rs::failed_sysdir_copies_leave_empty_readable_directories` (every level of the three keys, plain and `$PATH`-expanding refusals; fails with the repair removed, mutation-checked under ASan) and `common.rs::unit_tests::failed_sysdir_copies_are_repaired`. Reviewed by hand with no further candidate: `init`'s ceiling and poison paths, `Runtime`'s single release, the pin ordering of every allocating key, `buf_string`'s copy bounds (`size + 1` bytes, NUL from `git_buf_fromstr`) and dispose, `extensions`' empty-array adoption, `set_extensions`' empty slice, `set_cache_object_limit` with the 4 in-range `ObjectType`s (C's error path, which would set an error pre-init, is unreachable), `windows_sharemode`'s unwritten out-param. After the fix: plain, ASan/UBSan (with LSan) and TSan are clean on the whole workspace, BSan and Miri on every `common` / `global` suite. |
